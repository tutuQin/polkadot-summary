## 5.3 EVM vs PVM：Fibonacci 计算效率对比

视频 5.3 用 Fibonacci 计算作为一个「纯计算」的基准任务，对比 EVM 与 PVM 在执行效率上的差异。

可总结为：

- 先说明 EVM 与 PVM 的定位：EVM 是以太坊兼容虚拟机，而 PVM 是 Polkadot 生态下针对某些场景优化的虚拟机（如更适配特定语言或执行模型），两者在指令集、资源计费、执行策略等方面有差异。
- 选择 Fibonacci 作为对比用例：Fibonacci 递归/迭代计算是典型 CPU 密集型任务，适合用来测试 VM 的算力利用与执行开销。
- 分别在 EVM 和 PVM 上实现 Fibonacci 逻辑（思路相同但运行环境不同），为 5.4 的性能测试做准备。

这部分在 `lesson-5.md` 中可以写成「5.3 以 Fibonacci 为例理解 EVM 与 PVM 的差异」，重点放在为什么选 Fibonacci 以及它暴露的 VM 特性（如调用开销、gas 消耗等）。

## 5.4 EVM vs PVM：性能实测对比

视频 5.4 在上一节 Fibonacci 实现的基础上，真正对 EVM 与 PVM 做「性能实测」。

文档中可以抓住这些点：

- 测试方法：在相同输入规模（如相同 n 值）下，分别在 EVM 和 PVM 中调用 Fibonacci 计算，记录执行时间、资源消耗（例如 gas 或对应计费单位）。
